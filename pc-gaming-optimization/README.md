# Оптимизация ПК под игры (Windows 10/11)

Безопасный скрипт: только обратимые настройки, перед изменениями создаётся
точка восстановления и резервная копия. Не отключает Защитник, обновления,
службы и не лезет в драйверы.

## Как запустить

1. Скачай папку `pc-gaming-optimization` (Code → Download ZIP) и распакуй.
2. Дважды кликни **`optimize.bat`** → согласись на запрос администратора.
3. Прочитай пункты с `[!]` в конце — это то, что надо поправить руками.
4. **Перезагрузи ПК.**

Откатить всё обратно: **`restore.bat`**.

Дополнительные опции (запуск из PowerShell от администратора):

```powershell
powershell -ExecutionPolicy Bypass -File .\optimize.ps1 -VisualEffects  # ещё и выключить анимации Windows
powershell -ExecutionPolicy Bypass -File .\optimize.ps1 -SkipCleanup    # не чистить временные файлы
```

## Что делает скрипт

| Настройка | Зачем |
|---|---|
| Схема питания «Максимальная производительность» | Процессор не сбрасывает частоты → меньше просадок и фризов |
| Игровой режим Windows | Система отдаёт приоритет игре |
| Выключена фоновая запись Xbox Game DVR | Она постоянно грузит видеокарту |
| Аппаратное планирование GPU (HAGS) | Меньше задержка ввода, иногда +FPS |
| Приоритет игр в планировщике, снято сетевое ограничение | Стабильнее кадры и пинг |
| Выключено ускорение мыши | Прицел двигается 1:1 |
| Запрещены фоновые приложения из Store | Меньше мусора в фоне |
| Очистка `%TEMP%` и `Windows\Temp` | Место на диске |
| Проверка железа | Старый драйвер, одна планка ОЗУ, выключенный XMP, HDD, автозагрузка |

## Что сделать вручную (даёт больше всего FPS)

1. **Драйвер видеокарты** — свежий с сайта NVIDIA / AMD / Intel (при установке — «чистая установка»).
2. **XMP / EXPO в BIOS** — память часто работает на 2133–2666 МГц вместо заявленных 3200–6000. Включение профиля даёт +10–20% FPS в процессорозависимых играх.
3. **Две планки ОЗУ** вместо одной (двухканальный режим).
4. **Игры на SSD**, а не на HDD — пропадают подгрузки и статтеры.
5. **Монитор**: Параметры → Система → Дисплей → Расширенные параметры → выставь максимальную частоту (144/165/240 Гц). Кабель — DisplayPort, и подключён в **видеокарту**, а не в материнку.
6. **Автозагрузка**: Ctrl+Shift+Esc → Автозагрузка → отключи всё лишнее (лаунчеры, торренты, обновлялки).
7. **Перед игрой** закрывай браузер (особенно Chrome с кучей вкладок) и Discord-оверлей, если не нужен.
8. **Панель NVIDIA**: «Режим управления электропитанием» → «Предпочтителен режим максимальной производительности»; «Режим низкой задержки» → «Вкл». В игре — **NVIDIA Reflex: Вкл + усиление**, если есть.
9. **AMD Adrenalin**: включи Anti-Lag; Radeon Chill выключи.
10. **В самой игре** самые «дорогие» настройки — тени, объёмное освещение/облака, сглаживание, трассировка лучей. Включи DLSS / FSR / XeSS в режиме «Качество».
11. **Температуры** — проверь в HWiNFO или MSI Afterburner. Если CPU/GPU выше ~90 °C — почисти от пыли и замени термопасту, иначе железо сбрасывает частоты.
12. **Ноутбук** — играй только от зарядки, включи режим «Производительность» в фирменной утилите производителя.

Если после всего игра всё равно лагает — пришли модель процессора, видеокарты,
объём ОЗУ и название игры: подскажу, что именно упирается.
